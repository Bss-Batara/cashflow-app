# Automated deployment

Frontend changes are published automatically by GitHub Pages after a push to
`main`.

Backend Apps Script deployment is prepared in
`.github/workflows/deploy-apps-script.yml`. Configure these repository secrets
once in GitHub under **Settings → Secrets and variables → Actions**:

- `CLASP_SCRIPT_ID`: Apps Script project ID.
- `CLASP_DEPLOYMENT_ID`: existing web-app deployment ID.
- `CLASP_CREDENTIALS`: the JSON content generated by `clasp login`.

After the secrets exist, every push that changes `backend/apps-script/` will
validate, push the source, and update the existing web-app deployment.
